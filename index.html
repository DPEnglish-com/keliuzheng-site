    秩与解的结构

    第 3 讲 · 21:08

    秩是行空间的维数，也等于列空间的维数；它衡量矩阵独立信息的多少。

    “行秩和列秩相等，这是结论；先抓住行空间，秩就有定义了。”

    A 有 n 列时，r(A) + dim N(A) = n。列满秩只保证“有解时唯一”，不是无条件有唯一解。

    r(A) + dim N(A) = n

    “先看列数，再看秩。解的自由度，就是列数减秩。”

    初等行变换不改变行空间；化成行阶梯形后，非零行的数量就是秩。

    “行变换只是在换一组基，空间本身没动，所以秩不会变。”

    A 是 3×5 矩阵且 r(A)=3 时，dim N(A)=5−3=2。减的是列数，不是行数。

    “我不急着解方程，先把秩数出来，后面就只剩写参数。”

    r(A+B) ≤ r(A)+r(B)，等号只是特例；r(AB) ≤ min{r(A), r(B)}。

    “rank(A+B) 最多是两者之和，等号成立是特例，不是规律。”

    非齐次方程 Ax=b 有解，当且仅当 r(A)=r([A|b])；有解时自由度是 n−r(A)。

    “参数题不是难题，它只是把秩的讨论拆成了几种情况。”
